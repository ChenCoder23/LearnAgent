# 初学者常见报错速查

卡住时按这个顺序做：**读报错最后一行 → 读它上面箭头指的那一行代码 → 打印相关变量的值和类型 → 再动手改**。

## 一、还没开始写就报错

| 现象 | 原因 | 解决 |
| --- | --- | --- |
| `uv: command not found` | 没装 uv 或不在 PATH | 按 `docs/05-环境搭建与排错.md` 装 uv |
| `ModuleNotFoundError: No module named 'fastapi'` | 没装阶段一依赖 | `uv sync --extra stage1` |
| `ModuleNotFoundError: No module named 'langchain'` | 没装阶段二依赖 | `uv sync --extra stage2` |
| `uv sync` 报 `os error 17` | 本机 uv 缓存跨卷 | 已在 `pyproject.toml` 配好 `cache-dir`，见环境排错文档 |
| 终端里中文是乱码 | PowerShell 编码 | `$env:PYTHONUTF8="1"; chcp 65001` |

## 二、语法类报错（写完一运行就炸）

| 报错 | 典型写法 | 正确写法 |
| --- | --- | --- |
| `IndentationError` | `if x > 1:` 后面直接换行写 `print(...)` | 冒号后面必须缩进 4 个空格 |
| `TabError` | 有的行用 Tab，有的用 4 空格 | 全文统一用 4 个空格 |
| `SyntaxError: invalid syntax` 指向 `if x = 1:` | 条件里用了赋值号 | 判断相等用 `==` |
| `SyntaxError: expected ':'` | `for i in range(3)` 少了冒号 | 循环、判断、函数定义行尾都要 `:` |
| `SyntaxError: unmatched ')'` | 括号没配平 | 从报错位置往前数括号 |

## 三、运行类报错（最常遇到的七个）

### `NameError: name 'total' is not defined`

```python
total = total + 1     # total 还没定义过
```

先给初值：`total = 0`。另一个常见原因是缩进错位导致变量定义在别的作用域里。

### `TypeError: unsupported operand type(s) for +: 'int' and 'str'`

```python
"年龄：" + 18                  # 错
f"年龄：{18}"                  # 对
"年龄：" + str(18)             # 也对
```

判断线索：**打印 `type(变量).__name__`**，你会立刻看到一个是 `int`、一个是 `str`。

### `TypeError: 'NoneType' object is not iterable`

你 expected 一个列表，实际拿到了 `None`。八成是某个函数**忘了写 `return`**。
检查你写的函数：有没有 `return result`？

### `IndexError: list index out of range`

```python
numbers = [1, 2, 3]
numbers[3]           # 越界：合法下标是 0/1/2
```

遍历列表时不要用下标硬套长度，优先 `for item in numbers`。

### `KeyError: 'xxx'`

字典里没有这个键。要么先判断，要么用默认值：

```python
if "xxx" in data: ...
data.get("xxx", 0)
```

### `ValueError: invalid literal for int() with base 10: 'abc'`

`int()` 只能转纯数字字符串。要么先校验，要么捕获异常给出友好提示。

### `ZeroDivisionError: division by zero`

```python
if count == 0:
    return 0.0
return total / count
```

## 四、逻辑错了但不报错（最难查的一类）

| 现象 | 常见原因 |
| --- | --- |
| 函数返回 `None` | 忘了 `return`，或者 `return` 写在了 `if` 里面 |
| 循环每次都拿到同一个值 | 变量在循环外定义，忘了在循环体内更新 |
| 修改了列表，结果原始数据也变了 | 两个名字指向**同一个列表**，需要 `list(...)` 拷一份 |
| 循环只跑了一次 | 循环体里不小心 `return` 了 |
| 条件永远为真 | 把 `=` 和 `==` 搞混，或者忘了更新 while 的计数 |

排查方法：在循环体第一行 `print(变量)`，看它真实的值，而不是你以为的值。

## 五、测试相关的疑问

| 现象 | 说明 |
| --- | --- |
| 看到 `NotImplementedError: TODO: ...` | 正常，这是题目还没做 |
| 测试头部显示 `LEARN_TARGET = solutions` | 你在跑参考答案，跑自己的代码前 `Remove-Item Env:LEARN_TARGET` |
| 只有 1 个测试失败，其他都过 | 看失败那条的 `assert` 右侧期望值，通常只差边界条件 |
| 整章都收集不到测试（ERROR） | 多半是模块 import 时就报错了，先单独跑 `uv run python labs/xx/lab.py` 看真实报错 |

## 六、真正卡住超过 40 分钟怎么办

1. 把问题**压缩成一句话**（「我调用 X 时得到 Y，期望 Z」）——写出来常常就找到答案了；
2. 打开同目录的 `solutions.py`，**只看卡住的那个函数**；
3. 关掉文件，用自己的话把逻辑写一遍，再跑测试；
4. 第二天回来重做一遍这道题，能独立写出来才算真的会。
