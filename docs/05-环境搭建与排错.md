# 环境搭建与排错

## 一次性准备

```powershell
# 1) 确认 uv 可用（本项目用它管理 Python 版本和依赖）
uv --version

# 2) 安装依赖：dev + 阶段一后端 + 阶段二 LangChain
uv sync --extra dev --extra stage1 --extra stage2

# 3) 自检
uv run python -m learnkit.progress
```

Python 版本由 `.python-version` 固定为 3.11，`uv` 会自动下载并使用，不需要你手动安装。

## 本机已知问题与解法

### uv 报 `os error 17`（系统无法将文件移到不同的磁盘驱动器）

现象：`uv sync` 反复重试并失败在 `...\uv\cache\interpreter-v4\...msgpack`。
原因：这台机器的 uv 缓存目录与临时目录处在不同卷。

解法已经写进 `pyproject.toml`：

```toml
[tool.uv]
cache-dir = "E:/Tmp/uvcache"
```

换机器时删掉这段，或改成自己机器上的路径。也可以只在当前终端临时指定：

```powershell
$env:UV_CACHE_DIR="E:\Tmp\uvcache"; uv sync
```

### PowerShell 里中文输出乱码

```powershell
$env:PYTHONUTF8="1"
chcp 65001
```

## 常见报错对照表

| 报错 | 含义 | 处理 |
| --- | --- | --- |
| `NotImplementedError: TODO: ...` | 正常现象：这道题还没做 | 按 docstring 实现 `lab.py` |
| `ModuleNotFoundError: fastapi` | 没装阶段一依赖 | `uv sync --extra stage1` |
| `ModuleNotFoundError: langchain` | 没装阶段二依赖 | `uv sync --extra stage2` |
| `assert 3 == 1` | 实现与测试期望不一致 | 读测试里的注释，它通常就是需求 |
| 测试头部显示 `LEARN_TARGET = solutions` | 你正在跑参考答案 | 跑自己的代码前执行 `Remove-Item Env:LEARN_TARGET` |
| pytest 收集不到测试 | 命令行路径写错 | 在仓库根目录执行，或写全 `tests/test_xx.py` |

## 测试怎么跑最顺手

```powershell
uv run pytest tests/test_02_functions.py -v            # 详细模式，看到每个用例名
uv run pytest tests/test_02_functions.py -k retry      # 只跑名字含 retry 的用例
uv run pytest -x                                       # 遇到第一个失败就停
$env:LEARN_TARGET="solutions"; uv run pytest           # 全量验证题目本身（应全绿）
```

## 关于 API Key

阶段二、三的所有测试都用离线假模型，**不配置 Key 也能 100% 完成**。想接真实模型时：

```powershell
$env:OPENAI_API_KEY="sk-..."
uv run python labs/10_llm_prompt_parser/real_api_demo.py
```

真实模型调用只用于人工冒烟测试，不要写进自动化测试（不确定的测试等于没有测试）。
