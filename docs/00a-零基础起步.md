## 1. 先把「代码怎么跑起来」这件事搞清楚

Python 是一个**解释器**：你写一个 `.py` 文本文件，解释器从第一行开始，一行一行往下执行。
和你平时双击 exe 不一样，代码不会自己「变成程序」，而是被逐行翻译执行。

## 2. 变量：名字贴在值上

变量**不是盒子，是标签**。`age = 18` 的意思是「把 `age` 这个名字贴到 `18` 这个值上」，
后面你可以把同一个名字贴到别的值上：

```python
age = 18
print(age)        # 18
age = age + 1     # 先算出 19，再让 age 指向 19
print(age)        # 19
name = "小明"      # 字符串要加引号
price = 9.9       # 小数直接写
is_student = True # 只有 True / False
nothing = None    # 表示「还没有值」
```

命名规则（会被强制检查）：

- 只能用字母、数字、下划线，且**不能以数字开头**：`user_name` 可以，`1name` 不行；
- 大小写敏感：`Name` 和 `name` 是两个不同的名字；
- 推荐全小写 + 下划线（`total_price`），这是 Python 社区的约定。

## 3. Python 的四种基本类型

```python
print(type(18).__name__)      # int     整数
print(type(9.9).__name__)     # float   小数
print(type("hi").__name__)    # str     字符串
print(type(True).__name__)    # bool    布尔
print(type(None).__name__)    # NoneType
```

`type(值).__name__` 是你以后排查问题的常用动作：**不确定它是啥，就打印它的类型**。

类型转换（转不动就报错，这是好事，别急着用 try 吞掉）：

```python
int("12")        # 12
float("1.5")     # 1.5
str(12)          # '12'
int("abc")       # 报错 ValueError：invalid literal for int()
```

## 4. 运算

```python
7 + 2      # 9
7 - 2      # 5
7 * 2      # 14
7 / 2      # 3.5   注意：除法结果一定是小数
7 // 2     # 3     整除，只取整数部分
7 % 2      # 1     取余（判断奇偶、整除最常用）
2 ** 10    # 1024  幂
```

比较运算的结果永远是布尔值：

```python
18 >= 18     # True
18 == 18     # True   注意是两个等号！一个等号是赋值
18 != 20     # True
```

逻辑运算：`and`（都真才真）、`or`（一个真就真）、`not`（取反）。

```python
age = 20
age >= 18 and age < 60     # True
not True                   # False
```

字符串也能运算，但含义不同：

```python
"a" + "b"     # 'ab'    拼接
"a" * 3       # 'aaa'   重复
```

## 5. 字符串：你以后用得最多

```python
s = "Hello World"
len(s)              # 11        长度
s.lower()           # 'hello world'
s.upper()           # 'HELLO WORLD'
s.replace("l", "L") # 替换
s.split()           # ['Hello', 'World']      按空白切成列表
s[0]                # 'H'        下标从 0 开始
s[-1]               # 'd'        负数从后往前数
s[0:5]              # 'Hello'    切片：取 0 到 4（不含 5）
"-".join(["a", "b"]).   # 'a-b'   用分隔符把列表粘回字符串
```

**f-string**（格式化字符串）是打印信息的主力工具，前面加 `f`，花括号里可以直接放变量或表达式：

```python
name, price, count = "苹果", 3.5, 2
print(f"{name} x{count} = {price * count:.2f} 元")
# 苹果 x2 = 7.00 元     :.2f 表示保留两位小数
```

## 6. 让程序做判断

**缩进就是语法**。Python 用行首的四个空格表示「这些行属于上面的 if」：

```python
score = 88
if score >= 90:
    print("优秀")           # 有缩进 -> 属于 if
elif score >= 60:
    print("及格")           # 再判断
else:
    print("不及格")         # 都不满足时执行
print("判断结束")            # 没缩进 -> 一定会执行
```

常见错误：把 `=` 写成 `==`（或者反过来）；忘了行尾的冒号 `:`；缩进用了 3 个空格和 4 个空格混着用。
Python 只要求「同一块里一致」，但请**统一用 4 个空格**。

## 7. 让程序重复做事

`for` 用来「把一串东西逐个拿出来用」：

```python
total = 0
for number in range(1, 5):     # range(1, 5) 得到 1,2,3,4（不含 5）
    total = total + number     # 也可以写成 total += number
print(total)                   # 10
```

遍历列表、字符串都一样：

```python
for ch in "abc":
    print(ch)

names = ["小明", "小红"]
for name in names:
    print(f"你好，{name}")

for index, name in enumerate(names):    # 同时要下标时用 enumerate
    print(index, name)                  # 0 小明 / 1 小红
```

`while` 是「条件为真就一直转」，**必须让条件最终变假**，否则会死循环（按 Ctrl+C 中断）：

```python
n = 3
while n > 0:
    print(n)
    n -= 1        # 少了这行就是死循环
```

`break` 立刻跳出循环，`continue` 跳过这一轮剩下的语句：

```python
for n in range(1, 10):
    if n == 3:
        continue      # 跳过 3
    if n == 6:
        break         # 到 6 就整个结束
    print(n)          # 1 2 4 5
```

## 8. 列表和字典：装数据的两个容器

**列表**：有顺序、可以改。

```python
numbers = [3, 1, 2]
numbers.append(9)      # [3, 1, 2, 9]
numbers[0]             # 3
numbers[-1]            # 9
len(numbers)           # 4
9 in numbers           # True    成员判断
sorted(numbers)        # 返回排序后的新列表
```

**字典**：按名字查值。

```python
ages = {"小明": 18, "小红": 20}
ages["小明"]              # 18
ages["小刚"] = 21         # 新增
ages.get("小李", 0)       # 0       不存在也不会报错（推荐）
# ages["小李"]            # 会报 KeyError —— 这就是要用 get 的原因
for name, age in ages.items():
    print(name, age)
```

「统计出现次数」是这两者的经典组合，几乎每本教材都会问：

```python
text = "aba"
counts = {}
for ch in text:
    counts[ch] = counts.get(ch, 0) + 1
print(counts)      # {'a': 2, 'b': 1}
```

## 9. 函数：把一段逻辑起个名字

```python
def add(a, b):          # def 定义函数，a b 是参数
    return a + b        # return 把结果交出去

print(add(1, 2))        # 3
```

要点：

- `return` 之后的代码不会执行；没有 `return` 的函数返回 `None`；
- 参数可以给默认值：`def greet(name, greeting="你好")`，调用时可以不传第二个；
- 函数名要能说明它做什么（`calc_total_price` 比 `f2` 好一万倍）。

## 10. 怎么读报错信息

报错**不是坏事**，它是解释器在告诉你哪里不认。看最后一行：

| 报错 | 意思 | 常见原因 |
| --- | --- | --- |
| `NameError: name 'x' is not defined` | 用了没定义的名字 | 拼写错、忘了赋值、缩进导致作用域不对 |
| `TypeError: can only concatenate str (not "int") to str` | 类型不匹配 | 字符串和数字直接相加，要 `str(...)` 或 f-string |
| `IndentationError: expected an indented block` | 缩进有问题 | 冒号后面没缩进，或空格 Tab 混用 |
| `IndexError: list index out of range` | 下标越界 | 访问了 `numbers[10]` 但列表只有 3 个元素 |
| `KeyError: 'x'` | 字典里没这个键 | 改用 `.get()` 或先 `in` 判断 |
| `ValueError: invalid literal for int()` | 转换失败 | `int("abc")`，字符串里不是数字 |
| `ZeroDivisionError: division by zero` | 除以 0 | 先判断除数是否为 0 |

额外技巧：

- 想知道「值到底是什么」，就在出错前一行 `print(repr(值))`；
- 想确认「有没有执行到这里」，临时打一行 `print("到这里了")`；
- 不要一看到报错就上网搜，**先读报错最后一行 + 上面那行箭头指的位置**，八成能自己解决。
