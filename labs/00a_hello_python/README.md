### 变量不是盒子，先理解“名字指向对象”

你可能习惯把变量想成一个装值的盒子。学 Python 时，换成“名字贴在对象上”会更好理解。比如 `a = [1]`，右边先创建一个列表对象，左边的 a 只是绑定到它的名字。接着写 `b = a`，没有再造一个列表，两个名字指向的是同一份东西。

所以你通过 b 追加元素，a 也能看见；但如果写 `b = [9]`，只是让 b 改为指向一个新列表，a 还指着旧列表。这就是“修改对象”和“重新绑定名字”的区别。Python 用这一套模型处理函数传参、容器元素和对象属性，先弄清它，后面很多坑就不用硬背了。

类型跟着对象走，不是永远写死在变量名上。a 现在指向列表，下一行也可以指向字符串。不过能这么写，不代表业务里频繁换类型好读。给名字一个稳定含义，代码通常更容易理解。

```python
a = [1]
b = a
b.append(2)
assert a == [1, 2]
b = [9]
assert a == [1, 2]
```

这里 `a is b` 问的是两者现在是否指向同一个对象，`a == b` 问的是值是否相等。比较空值常用 `is None`；比较业务里的字符串和数字，一般用 `==`。

### 表达式产出值，语句安排动作

`2 + 3`、`age >= 18`、`name.upper()` 都是表达式，它们会计算出一个值。赋值、if、for、return 则在安排程序怎么往下走。你写代码时可以先想清楚：现在是在算一个值，还是在决定下一步做什么？

比较表达式本身就返回 bool，所以条件判断的结果可以直接返回。Python 也提供条件表达式 `a if condition else b`，适合表达简单的二选一；分支里需要做很多事时，还是展开成 if 更清楚。

运算顺序按优先级决定，括号能明确你的意图。`/` 是除法，`//` 是向下取整的整除，负数时不能理解成简单截掉小数；`%` 是余数，`**` 是幂。

```python
assert 7 / 2 == 3.5
assert -7 // 2 == -4
assert 1 < 2 < 3  # 连续比较会串联比较关系
answer = "yes" if 3 > 2 else "no"
assert answer == "yes"
```

Python 会把 `a < b < c` 理解成两段比较，中间的 b 只求值一次。想判断某个比较结果是不是 True，写 `(3 >= 2) is True` 更直接；实际代码通常直接用 `3 >= 2` 就行，不需要和 True 再比较一次。

### 函数把计算过程变成一个可以传递的对象

写 `def` 时，你是在创建一个函数对象，再把名字绑定到它。函数体不会因为定义完就立刻执行，得等调用。括号里的参数是在说明“调用时把哪些值交进来”，`return` 则是在说明“这次把什么结果交出去”。

函数在 Python 里也是普通对象，可以赋给另一个名字、放进列表、作为参数传进去，也可以作为返回值。语言不用额外发明一种“回调类型语法”，就能让排序、事件处理、数据转换使用同样的机制。

```python
def double(value):
    return value * 2

operation = double
assert operation(3) == 6
assert list(map(operation, [1, 2])) == [2, 4]
```

`operation = double` 传的是函数本身，`operation = double(3)` 传的是执行结果，这两句差别很大。没有写 return 的函数会返回 None。print 只是输出到屏幕，不能拿它代替函数返回值；把计算和显示分开，函数才更容易复用和测试。

### 字符串不可变，格式化负责把数据变成展示文字

字符串是一串 Unicode 文本。你调用 strip、replace、upper，得到的是处理后的字符串，原字符串没有被原地改掉。这样同一份字符串被多处共享时，就不用担心别人突然改了内容。

f-string 是把数据放进展示文字的一种方便写法：花括号里可以写变量或表达式，冒号后面可以写格式规则。`:.2f` 表示显示两位小数，处理的是显示样子，不是给后续计算创造一种更精确的数字。

```python
name, price = "茶", 3.5
line = f"{name}: {price:.2f}"
assert line == "茶: 3.50"
assert "  a  b ".split() == ["a", "b"]
assert " / ".join(["a", "b"]) == "a / b"
```

split 把文字拆成小段，join 把小段连起来。join 写在分隔符上，是因为连接时最明确的规则就是“中间插什么”；待连接的内容可以来自列表，也可以来自其他可迭代对象，但每项都得是字符串。文本长度、字符和模型 token 是不同概念，后面做模型上下文预算时还会遇到这个区别。

## 原理明白了，再看看这章会怎样用到它们

### 变量与类型

名字绑定到对象；int 是整数，float 是浮点数，str 是字符串，bool 表示真假，None 表示没有值。类型注解描述期望类型，但不会自动转换实参。

### 表达式与数值运算

+、-、*、/ 分别是加减乘除；/ 返回浮点结果，// 是向下取整的整除，% 是余数，** 是幂。圆面积用 math.pi，温度转换注意运算顺序。

### 字符串与返回值

f-string 的花括号会计算表达式；:.2f 输出两位小数的字符串。小票中的数量应来自 count，金额来自 price * count，标点和空格也是结果的一部分。

### 默认参数与异常

discount=0.0 表示调用者省略该参数时不打折。int("abc") 会抛 ValueError；空列表求平均之前也应先抛出约定的异常。

## 顺着这章，还能多理解一点什么

浮点误差使数学上相等的结果可能不完全相等，测试用 pytest.approx 比较。金额业务通常用 Decimal，第 03 章会介绍。

## 先看一小段代码，把语法拆开聊

```python
def label(name: str, amount: float = 0.0) -> str:
    return f"{name}: {amount:.2f}"

left, right = 1, 2
left, right = right, left
assert label("示例", 2) == "示例: 2.00"
```

参数 name: str 是注解，amount=0.0 是默认值，-> str 描述返回类型。return 结束函数；两个逗号分隔的值可以构成元组，赋值时也可以解包。

顺便认一下题目里常见的注解：`list[str]` 是“里面放字符串的列表”，`str | None` 是“字符串或者空值”，`->` 后面写返回什么类型。它们主要是在说明接口，不会替你检查或转换输入。`from __future__ import annotations` 则让注解暂时不求值，第 16 章会用到这个细节。
